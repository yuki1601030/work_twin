# Work Twin City

Work Twin City は、会社全体を「広い街」、部署を「エリア」、社員一人ひとりの Work Twin を「家」として表現する未来のキャリア体験モックです。社内情報や実在の個人情報は使わず、すべてコード内の架空データで構成しています。

## 画面で表現していること

- スクロールして探索する広い街マップ
  - 開発区、事業企画区、人事区、新規事業区、データ分析区、営業区、カスタマーサクセス区、製造・現場改善区を配置
  - Work Twin の家、協業の道、空き部屋・入居者募集・引っ越し候補をマップ上に表示
  - 部署をまたいだ協業の道は少し太く青く表示
- Work Twin 詳細パネル
  - 所属エリア、ロール、家のタイプ、今期の主要成果、伸びたスキル、他者への貢献、関わった人、次期の成長テーマ、引っ越し候補を表示
- 空き部屋パネル
  - 募集エリア、必要なロール、求めるスキル、ミッション、緊急度、推薦される社員を表示
- 部署エリアパネル
  - 住人の数、空き部屋数、部署横断の道の数、エリアの説明を表示
- Work Twin の「家の中」ビュー
  - 成果の部屋、スキルの部屋、協業の部屋、支援の部屋、学習の部屋、評価の部屋、キャリアの部屋を表示
  - 公開範囲・提出範囲のトグルで、本人主導の証跡管理であることを表現
- 半期成果レポート生成
  - 1〜2秒程度の生成ステップを挟み、成果サマリー、成果の根拠、発揮されたスキル、協業・支援の記録、次期の成長テーマ、評価コメント案、履歴書・職務経歴書向けサマリーを生成するイメージ
- 複数の出力形式
  - 半期評価レポート、履歴書用サマリー、社内異動プロフィールを切り替え表示
- 時間変化
  - 前期、今期、来期予測を切り替え、部署状態・空き部屋・組織健康度が変わる街として表現
- 都市計画モード
  - 過負荷エリア、人材不足、空き部屋、協業ハブをハイライトし、右側パネルに会社全体へのAI提案を表示
- 引っ越し候補・シミュレーション
  - 社内公募や人材不足を「空き部屋」「入居者募集」として表現し、選択中の社員に合う候補と引っ越し時の影響を表示

## ローカルでの表示確認

静的ファイルだけで動作します。リポジトリ直下で以下を実行し、ブラウザで `http://127.0.0.1:4173` を開いてください。

```bash
python3 -m http.server 4173
```

## 実装ファイル

- `index.html` - アプリの画面構造、コンセプトコピー、スクロール可能な街マップ領域、固定詳細パネル
- `styles.css` - 広い街マップ、部署エリア、家タイプ別の見た目、協業道路、カードUI、レスポンシブ表示のスタイル
- `app.js` - 架空データ、SVG協業道路の生成、クリック操作、詳細表示、時間変化、都市計画モード、公開範囲トグル、空き部屋推薦、レポート生成ロジック

## 今後追加するとよい機能案

- Work Twin の家が成果に応じて段階的に増築されるアニメーション
- 本人が公開範囲を選べる証跡カード
- 引っ越し候補を成長テーマ、希望職種、空き部屋要件でフィルタする機能
- 半期レポートの編集・承認フロー
- 部署間の協業の道をプロジェクト単位でハイライトする機能
- 街の時間経過ビュー（半期ごとに家や道がどう増えたかを再生）
