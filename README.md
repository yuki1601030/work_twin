# Work Twin City

Work Twin City は、会社全体を「街」、部署を「エリア」、社員の Work Twin を「家」として表現する未来の人材OSコンセプトモックです。社内情報や実在の個人情報は使わず、すべてコード内の架空データで構成しています。

## 画面で表現していること

- 会社全体の街マップ
  - 開発区、事業企画区、人事区、新規事業区をエリアとして配置
  - Work Twin の家、協業の道、空き部屋・入居者募集をマップ上に表示
- Work Twin 詳細パネル
  - 今期の主要成果、伸びたスキル、支援した相手、関わったプロジェクトを表示
- 部署状態パネル
  - 部署エリアをクリックすると、街の活気、協業数、空き部屋数を表示
- 半期成果レポート生成
  - 評価シートを書くのではなく、本人が承認したAI要約の成果証跡からレポート案を生成するイメージ
- 引っ越し候補
  - 社内公募や人材不足を「空き部屋」「入居者募集」として表現

## ローカルでの表示確認

静的ファイルだけで動作します。リポジトリ直下で以下を実行し、ブラウザで `http://127.0.0.1:4173` を開いてください。

```bash
python3 -m http.server 4173
```

## 実装ファイル

- `index.html` - アプリの画面構造
- `styles.css` - 街マップ、家、道、カードUI、レスポンシブ表示のスタイル
- `app.js` - 架空JSONデータ、クリック操作、詳細表示、レポート生成ロジック

- 半期レポートの編集・承認フロー
- 部署間の協業の道をプロジェクト単位でハイライトする機能
